## NoSQL & Database Workspaces (ใหม่)
1. **Notion & Airtable** — Create Page/Record, Query Database, Update Properties, Delete Record
   - Auth: Notion API Key / Airtable PAT + Base ID + Table + Fields (JSON)
   - ตัวอย่าง: Extract → Notion (สินค้าใหม่ลง Database)
   - ใช้กับงานพี่: เก็บ log รอบส่งเป็นฐานข้อมูลแทนไฟล์ได้
2. **Coda & Open-Source (NocoDB/Baserow/SeaTable)** — List/Create/Update/Delete Row + Document Automation
   - ตัวอย่าง: HTTP → NocoDB (log ระบบลง DB ส่วนตัว)

## Communication & Productivity (ใหม่)
3. **Twilio (SMS/Voice)** — Send SMS / Make Voice Call / Get Message Status
   - ตัวอย่าง: Task Failure → SMS เข้าเบอร์วิศวกร
   - ใช้กับงานพี่: รอบส่งพังตอนดึกโทรปลุกได้เลย
4. **Zoom** — Create Meeting / Get Details / List Registrants
   - ตัวอย่าง: Schedule → สร้างห้อง → Email ส่งลิงก์ทีม
5. **Clockify / Todoist / Mailgun** — Start-Stop Time Entry (จับเวลารันบอท) /
   Create-Complete Task / Send Transactional Email (ตามเปิดอ่านได้)
