## Mouse & Keyboard ระดับ OS
- **Move mouse / Click mouse** — พิกัด X-Y + Click Type (ดูรายละเอียดไฟล์ `33-commands-mouse-keyboard.md`)
- **Press key / Hotkey** — ปุ่มลัดระบบ (เช่น `Ctrl+V`, `Ctrl+C`, `Alt+Tab`)

## Network & API
- **HTTP Request** — GET/POST/PUT/DELETE + Headers/Body → Response/Status (ดูรายละเอียดไฟล์ `40-commands-flow-network-db-ocr.md`)
- สูตร: HTTP Request (POST JSON) → Convert text to JSON → Get value from dictionary
