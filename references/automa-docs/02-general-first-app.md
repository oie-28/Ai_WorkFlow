## Overview
ส่วนนี้จะสร้าง App แรกด้วย Automa เพื่อสั่งเบราว์เซอร์และซอฟต์แวร์ — เป็นฟังก์ชันพื้นฐานแต่สำคัญที่สุด

## Prerequisites
ติดตั้ง Automa + Automa extension สำหรับเบราว์เซอร์

## Create your first App
โจทย์ตัวอย่าง: เลขาต้องส่งแจ้งเตือนให้เพื่อนร่วมงานผ่าน WhatsApp อยากให้ Automa ทำให้อัตโนมัติ

App เกือบทั้งหมดของ Automa มี 3 ขั้นตอนเสมอ:
1. **Create an App:** เปิด Automa desktop → New → For PC
2. **Build a Flow:** เลือกคำสั่งฝั่งซ้าย ลากลง Canvas ทีละอันเหมือนต่อบล็อก
   แต่ละคำสั่ง = 1 action (เช่น [Print], [Open webpage])
3. **Run a Flow:** กด ►Run เพื่อรัน flow บน Canvas ผลลัพธ์แสดงที่ Logs

**Capture an Element:** กด Ctrl ค้าง + คลิก element ที่ต้องการ (ปุ่ม/ช่องกรอก)
element คือเป้าหมายที่จะสั่งงาน — การ capture คือการบอก Automa ว่าจะทำตรงไหน
