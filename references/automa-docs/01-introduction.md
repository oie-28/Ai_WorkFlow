## 1. What is Automa RPA?
Automa is a powerful RPA (Robotic Process Automation) tool — a small software bot that mimics
the real human clicks and keystrokes that people would do. It can automate time-consuming,
repetitive manual tasks with no coding required, like entering, retrieving, or processing data.

Automa offers a user-friendly solution tailored to your needs, allowing your teams to focus on
high-value work while ensuring operational efficiency, accuracy, and speed.

## 2. Download & Install
ต้องติดตั้ง 2 อย่าง: **Automa desktop app** + **Browser extension (Automa Scraper)** สำหรับควบคุมเว็บเพจ

**Automa desktop:** โหลดจากเว็บ official — รองรับ Windows และ Mac (Linux coming soon)

| ข้อกำหนด | Minimum | Recommended |
|---|---|---|
| CPU | 2 core (x86) | 4 core (x64) ขึ้นไป |
| Memory | 4 GB | 8 GB |
| Internet | 8 Mbps | 10 Mbps |
| OS | Windows 7 | Windows 10 |
| Browser | Edge | Chrome |

**Browser extension:** เลือกเบราว์เซอร์ที่ใช้บ่อยสุด (แนะนำ Chrome)
1. ปิดเบราว์เซอร์ก่อน
2. Avatar → Tools → Automation plug-ins → Install รอจนเสร็จ
3. เปิดเบราว์เซอร์ → `chrome://extensions` (หรือ `edge://extensions`) → เปิด Developer Mode + Automa Scraper
4. หมายเหตุ: อาจต้อง restart เบราว์เซอร์หลังเปิด Developer Mode
