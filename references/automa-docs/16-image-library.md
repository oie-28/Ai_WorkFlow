# Image Library — จับและสั่งงานด้วยรูปภาพ

> ที่มา: Features → Editor Window → Bottom Bar → Image Library
> วันที่บันทึก: 2026-09-16 | วิธีบันทึก: copy-paste จากเว็บ Docs

## แนวคิด
"Image Library" ใช้จับและจัดการ image element — รูปในนี้สั่งงานได้ด้วยคำสั่งชุด
**[Mouse & Keyboard]** และชุดคำสั่ง **[Image]**
