# Integrations — Marketing/HR + Ops Tools + Slides (ของใหม่)

> ที่มา: user ถอดเนื้อหามาให้ (ส่วน API Response/Queue/Trigger ที่ส่งมาด้วยซ้ำกับไฟล์ `55`/`56`/`11` — ดูไฟล์เดิม)
> วันที่บันทึก: 2026-09-16 | วิธีบันทึก: user copy + สรุปมาให้

## Marketing & HR (ใหม่)
1. **Mautic & Mailchimp** — Create Contact / Add to Segment / Trigger Campaign / Get Contact Details
   - ตัวอย่าง: Extract Form → Mautic (Contact ใหม่เข้า Segment) → Email
2. **BambooHR & Workday** — Get Employee / Time Off Request / Update Record
   - ตัวอย่าง: Schedule → ดึงคนลาวันนี้ → Slack

## Operations Tools (ใหม่)
3. **Bitly & URL Shortener** — Shorten URL / Analytics / Custom Domain
   - ตัวอย่าง: Extract Long URL → Bitly → Send SMS
   - ใช้กับงานพี่: ลิงก์ในข้อความส่งย่อก่อนได้
4. **Bannerbear** — Create Image from Template / Get Status
   - ตัวอย่าง: Extract สินค้า → สร้างแบนเนอร์ใหม่

## Cloud Docs (ใหม่: Slides)
5. **Google Drive & Dropbox** — Upload/Download/Create Folder/Move-Copy/Share
   - ตัวอย่าง: Export Excel → Drive แชร์ทีม (ท่าเดียวกับไฟล์ 66)
6. **Google Slides & Media (ใหม่)** — Create Presentation / Replace Text / Insert Image / Export PDF
   - ตัวอย่าง: Extract Sales → แทนเลขใน template → Export PDF → Email
   - ใช้กับงานพี่: ทำสไลด์สรุปผลรอบส่งอัตโนมัติได้
