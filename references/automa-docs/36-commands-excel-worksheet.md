# Commands — Excel Worksheet Management (5 คำสั่ง)

> ที่มา: Commands → Excel / Worksheet Management (user ถอดเนื้อหามาให้ครบ)
> วันที่บันทึก: 2026-09-16 | วิธีบันทึก: user copy + สรุปมาให้

1. **Create Excel worksheet** — สร้าง Sheet ใหม่ (Name เช่น `Report_2026` + Position: At the end / Before-After)
   - ตัวอย่าง: Open → Create (`Summary`) → Write
2. **Delete Excel worksheet** — ลบ Sheet (Name)
3. **Rename Excel worksheet** — เปลี่ยนชื่อ (Current → New เช่น `Sheet1` → `Data_Output`)
4. **Activate Excel worksheet** — สลับ Active Sheet ก่อนอ่าน/เขียน
   - ตัวอย่าง: Activate (`Data_Output`) → Read
5. **Copy Excel worksheet** — ก๊อปทั้ง Sheet (Source → New Name ในไฟล์เดิม/ไฟล์อื่น)
   - ตัวอย่าง: Copy (`Template` → `Report_Jan`) — ใช้ทำรายงานรายเดือนจากต้นแบบ
